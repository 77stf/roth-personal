# OFM — Cykl życia modelki

## Statusy

```
NIEZWERYFIKOWANA → ZATWIERDZONA → [aktywna] → zakończona
                → ODRZUCONA
```

### NIEZWERYFIKOWANA
- Pierwszy kontakt, wstępne rozmowy
- Brak podpisanej umowy
- Brak dostępu do konta

### ZATWIERDZONA
- Podpisana umowa
- Dostęp do konta przyznany
- Aktywnie zarządzana

### ODRZUCONA
- Rozmowy zakończone bez współpracy
- Powód dokumentowany w notatkach

## Onboarding checklist
- [ ] Rozmowa wstępna — zrozumienie celów
- [ ] Umowa podpisana
- [ ] Dostęp do konta / komunikacja ustalona
- [ ] Strategia contentu zaplanowana
- [ ] Pierwsze 30 dni — intensive monitoring

## Metryki
- Przychód miesięczny (realny)
- Wzrost subskrybentów
- Zaangażowanie (messages / PPV rate)
